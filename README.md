# VPS Backup Toolkit

Надёжный набор скриптов для полного бэкапа и восстановления Debian VPS.

## Возможности

- Полный бэкап конфигураций, пользователей, пакетов и файрвола
- Опционально — создание полного образа системы (tar.gz)
- Автоматическое восстановление на чистом Debian
- Сохранение паролей, SSH-ключей и прав пользователей
- Не требует LiveCD
- Работает на любом VPS с Debian 12/13

## Быстрый старт

### Бэкап

```bash
git clone https://github.com/ваш_юзер/vps-backup.git
cd vps-backup
